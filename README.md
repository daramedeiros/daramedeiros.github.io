# dara 🖥️

Portfólio de **Dara Medeiros**, product designer, UX e service designer em São Paulo.

🔗 **Acesse:** https://daramedeiros.github.io

## Sobre

Sou Product Designer Pleno na Smart Fit, onde desenho ferramentas internas para o time de operações. Comecei na área jurídica, passei pelo jornalismo e pelo front-end com a {reprograma} até chegar ao design. Acredito que design é estratégia de negócio.

## O que tem no site

O portfólio imita um desktop: a página tem pastas, janelas, um dock e uma barra de menu com o horário de São Paulo.

- **Superpoderes:** quatro áreas de atuação, cada uma com os resultados alcançados
- **Experiência:** janela no estilo Finder com Smart Fit, Uello, BRQ/Itaú e {reprograma}
- **about-me.txt:** minha trajetória
- **Recomendações:** depoimentos de colegas em formato de mensagens
- **Formação e contato**

## Tecnologia

O site é um único arquivo `index.html`, feito com HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build. Ele tem layout responsivo, modo claro e escuro automático e respeita a preferência de movimento reduzido. Está hospedado no GitHub Pages.
